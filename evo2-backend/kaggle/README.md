# Running the fine-tuning pipeline on Kaggle

`evo2-finetune.ipynb` is a **single self-contained notebook** that runs the whole
pipeline from `../finetune/` on Kaggle's free GPUs. No `kaggle` CLI, no source
dataset — the `finetune/` package is embedded in the notebook (cell 1) and
regenerated by `render.py`.

## Setup

1. Kaggle → **Create → New Notebook → File → Import Notebook** → upload
   `evo2-finetune.ipynb`.
2. That's it. Everything else is driven by the `STAGE` variable in cell 2 and the
   Kaggle UI.

Re-run `python kaggle/render.py` and re-import the notebook whenever you edit
`finetune/*.py`.

## The loop

Each run: set `STAGE`, set the accelerator + Internet (table below), **Save
Version** (Run All). Then, so the next run sees what this one produced:

> Add Input → **Notebook Output** → this notebook → latest version

Cell 3 restores `data/`, `features/`, `runs/` from that input automatically.

| STAGE | accelerator | Internet | notes |
| --- | --- | --- | --- |
| `datasets` | None | **on** | ClinVar + BRCA1 + hg38 (~25 min, once) |
| `extract` | **GPU T4 x2** | **on** | resumable; re-run until "60/60 shards on disk" |
| `merge` | None | off | |
| `train` | None | off | prints head vs zero-shot AUROC |
| `publish` | None | off | set `PUBLISH_RUN` first |
| `auto` | GPU T4 x2 | on | does the next unfinished stage each run |

**Use T4, not P100** — vortex imports flash-attn, which needs compute ≥ 7.5.

## Constraints baked in

- `WINDOW_SIZE = 2048` (cell 2), not 8192 — evo2_7b + an 8 kb activation doesn't
  fit 16 GB. This changes `FeatureConfig.tag()`, so features cache separately and
  the trained head records the window it was built with. Adjust up/down based on
  the `extract` smoke-test's reported peak VRAM.
- **bf16 on T4** is the one unknown that can't be checked without a GPU. T4 has no
  native bf16; if vortex forces it, the smoke test throws a dtype/kernel error on
  the first forward. Fallbacks: patch the model to fp16 after load, or switch to
  `evo2_1b_base` (needs `EMBEDDING_LAYER`/`EMBEDDING_DIM` edits in
  `finetune/config.py`).
- `N_SHARDS` must stay 60 across `extract` runs, or shard N stops meaning the same
  rows.
- Quotas: 30 GPU-h/week, ~9 h/session. `EXTRACT_HOURS = 8.0` stops the loop with
  time to spare to save. A 40 k-variant / 2 kb run is ~15–25 GPU-h ≈ 2–3 sessions.
- 20 GB working disk. hg38 (3 GB) is symlinked from the input, not copied. The
  evo2 HF checkpoint (~15 GB) re-downloads each session.

## Getting a trained head to the live endpoint

`publish` writes `out/runs/active/`. Download the notebook output (Kaggle UI →
Output → Download), then:

```
modal volume put evo2-finetune-data ./out/runs/active /runs/active
modal deploy main.py
```

## Common failures

| symptom | cause | fix |
| --- | --- | --- |
| `flash_attn_2_cuda ... undefined symbol: ...c10_cuda_check_implementation`, or `torch is 2.10.x, need 2.4.x` | Kaggle's `PIP_CONSTRAINT` silently forces torch back to the image's 2.10 | cell 2 clears `PIP_CONSTRAINT`/`UV_CONSTRAINT`; `build_gpu_env()` re-pins torch 2.4.1 + the flash-attn wheel last and asserts the version. Don't `import torch` before cell 5 finishes |
| `too many values to unpack` on first forward | flash-attn < 2.7.0 sneaked in | force-reinstall the pinned wheel |
| `transformer-engine 1.13 build failed` (egg_info / metadata-generation) | no wheel for 1.13; source build is picky | `build_gpu_env()` now continues past it — if the smoke test then fails needing TE, try a cu12 wheel (`pip install transformer_engine_cu12`) or `evo2_1b_base` |
| dtype / kernel error on first forward | bf16 on T4 | see "bf16 on T4" above |
| `CUDA out of memory` in the smoke test | window too large | lower `WINDOW_SIZE`, re-run |
| `extract` redoes finished shards | notebook output not re-attached, or `N_SHARDS` changed | attach latest Notebook Output; keep `N_SHARDS=60` |
| `ModuleNotFoundError: finetune` | ran cells out of order | Run All — cell 1 writes the package |
| `Restart & Run All` message, or `RuntimeError: ... already has a docstring` | the kernel imported torch on an earlier Run All; pip can't hot-swap a loaded C extension | Run → **Restart & Run All** (always use this, not plain Run All, for the `extract` stage). Wheels are cached, so the 2nd pass is quick |
